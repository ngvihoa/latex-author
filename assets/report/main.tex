This document demonstrates report structure, results tables, and citations in LaTeX.
Every measurement in the table is synthetic and serves only to demonstrate formatting.
These values are not results from a completed model evaluation or experiment.

\section{Objective}
A report should connect its method, setup, and evidence to its conclusions.
This example uses the document preparation system described by Lamport~\cite{lamport1994}.
\section{Method and setup}
